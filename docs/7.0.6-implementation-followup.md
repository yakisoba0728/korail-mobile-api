## 읽기 경로 실서버 후속 검증 — 2026-09-16

`scripts/verify_706_new_live.py`로 각 요청 간 최소 1.5초 간격을 두고
`smart.letskorail.com`에 직접 조회했다. 회원 자격이 필요한 조회는 제공된 계정으로
메모리 내에서 로그인했고 종료 시 서버 로그아웃했다. 계정·쿠키·승차권 식별자·
응답 원문을 출력하거나 저장하지 않았다. 이 스크립트는 변경 요청을 보내지 않는다.

`ERT900011`은 APK의 `error_json.json`에 있는 일반적인 “조회중 오류” 코드다.
첫 페이지 커서 4개를 생략하는 정적 1:1 차이는 수정하고 오프라인 테스트로
확인했지만, 그 수정만으로 서버 오류는 해결되지 않았다. 별도 디컴파일 추적에서도
비보호 필드명 오류는 발견되지 않았고 `Key`/`Lang`·정렬·메뉴·선행 대기열
조건은 일부 보호되어 원인을 특정하지 못했다. 따라서 기본 검색 경로를
`ScheduleViewSpecial`로 전환하지 않았다. 보호된 요청 상수와 앱 런타임 입력을
확인하기 전에는 임의 값으로 재요청하지 않는다.
