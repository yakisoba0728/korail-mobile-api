# 합격 기준

번호가 G9 부터인 것은 G1~G8 을 폐기했기 때문입니다. 코드와 커밋이 그 번호로 부르고 있어 그대로 둡니다.

## 보장

| ID | 보장 |
|---|---|
| G9 | 변경 응답 파싱 오류의 `.raw` 에 전체 응답을 보존하며 자동 재전송하지 않는다. 기존 KorailApiError 의 부분 원문은 `.parser_raw` 에 두고 다른 예외는 KorailProtocolError 로 감싼다. |
| G10 | star import·모든 하위 모듈 import 가 성공하고 `__all__` 의 모든 이름이 정의돼 있다. |
| G11 | `logout()` 서버 호출이 실패해도 로컬 세션·쿠키를 비우고 예외를 전파한다. 서버 세션 무효화 성공은 보장하지 않는다. |

## 파서·원문과 한계

선택값은 대체로 관대하게 읽되 파서별 조건이 다릅니다. 리무진 `trainList`·`seatList` 는 생략·null 이면 빈 목록,
비목록·비객체 행이면 오류입니다. 일반 좌석 재고, 예약 신원·금액 등 필수 값은 검증합니다.
봉투 판정은 전송 계층에 있으며 개별 파서를 직접 호출하면 성공 여부·봉투 타입을 재검사하지 않을 수 있습니다.
모든 하위 값 객체가 `raw` 를 갖지는 않습니다. 로그·예외·`raw` 는 **마스킹하지 않으므로** 기록·노출은 호출자 책임입니다.

| ID | 한계 |
|---|---|
| L7 | CartInfo 중첩 결제 상세 6객체의 String 59개는 타입화하지 않고 응답 `raw` 에 보존한다. 보호된 enum·리터럴 평문과 캡처 없는 필드의 서버 형식은 미확인이다. |

실행 명령·의존성·종료 코드는 [README.md](README.md)를 따릅니다. 통과는 실서버 수용의 증거가 아닙니다.
