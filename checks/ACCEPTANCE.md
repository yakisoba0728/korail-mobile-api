# 오프라인 검사 기준

`tests/test_dynapath_diagnostic.py`와 인증·간편 API·프록시 회귀는 기본 `2!` 헤더, 경로 목록·명시적 생략,
추가 HTTP 없음·설정 pickle·명시적 v1 보존과 profile/env의 제공값을 검사합니다. 오프라인 통과는 실서버 성공의 증거가 아닙니다.

## 검사하는 계약

**G9 — 변경 응답 파싱 실패:** `.raw`에 전체 응답을 남기고 자동 재전송하지 않습니다.
`KorailApiError`는 유형을 유지하며 부분 원문은 `.parser_raw`에 옮깁니다. 다른 예외는 `KorailProtocolError`로 감쌉니다.

**G10 — 공개 표면:** 내부 패키지(`_core`, `_domains`)를 포함한 모든 하위 모듈의 import와 패키지 루트의 star import가 성공하고 `__all__`의 이름이 모두 정의돼 있어야 합니다.
이 검사는 각 공개 API의 정상 동작이나 모든 모델의 필드 의미를 검증하지 않습니다.

**G11 — 로그아웃 정리:** 서버 로그아웃 중 예외가 발생해도 로컬 세션·쿠키를 비우고 예외를 전파합니다.
서버 세션 무효화 성공은 보장하지 않습니다.

**환불 대상 연결:** 실제 `get_refund_fee` 반환값의 성공 상태·비공개 조회 문맥과 환불 대상의
원표 창구번호·반환일·일련번호·비밀번호·동반자 이름·증빙번호가 일치해야 합니다. 직접 생성·직접 파싱한
수수료 응답, 다른 승차권 응답, 원표 반환일 누락은 환불 요청 전에 거절하며 자동 조회·재시도하지 않습니다.
`PaidTicket.from_refund_detail()`의 현재 판매일·원표 반환일 분리와 동반자 정보 복사, 조회 문맥·새 필드의
`repr` 숨김도 검사 대상입니다. 이 연결은 수수료 금액의 유효기간이나 서버 승인을 보장하지 않습니다.

**7.0.10 정합성:** 오류 사전 10,305코드·17,256메시지와 `WRD000058`의 한국어 2개월·영어 유지,
은행 직접 필드 `Device, Version, Key, AppVersion`, 환불·수수료 공통 필드 선행,
기본 `AppVersion=7.0.8`과 `7.0.10` override를 구분합니다. `-8204` 분류는 #32에서 관측된 서버 코드의 합성 응답으로만 검사하며,
기본 버전 조합(`AppVersion=7.0.8`·API `Version=250601003`)이 실서버에서 수용된다는 증거가 아닙니다. 좌석배정 `*2` 이상은 SDK 확장으로 유지합니다.

**문서 복구 예제:** 실제 오류 가이드 블록에 JSON `null` 예약 응답을 주어 `raw=None`이어도 `request_sent=True`이면 예약 내역을 다시 확인하고 예약을 재전송하지 않는지 검사합니다.
입력 거절은 예약 요청 0회입니다. 재계산 성공 뒤 선택 장바구니 요청이 실패해도 최신 홀드를 보존합니다.
`-8204`는 실패 예외 경로와 카드 결제·도우미석 안내의 FAIL 모델 경로를 구별하며 런타임 정책을 바꾸지 않습니다.

## 파서·원문과 한계

선택값은 대체로 관대하게 읽되 파서별 조건을 따릅니다. 리무진 `trainList`·`seatList`는 생략·null이면 빈 목록이며,
비목록이나 비객체 행은 거절합니다. 좌석 재고·호차·역 목록의 선택 필드 18개는 빠지면 앱 기본값(""·`None`)이고,
예약 신원·금액 등 필수값은 검증합니다. 개별 파서를 직접 호출하면 성공 여부·봉투 타입을 다시 검사하지 않을 수 있으며 모든 하위 객체가 `raw`를 갖지는
않습니다. 파싱 실패 때의 전체 `.raw`·`.parser_raw` 는 직접 호출해도 같습니다.
로그·예외·`raw`는 **마스킹하지 않으므로** 기록·노출은 호출자 책임입니다.

**L7 — 미모델링 필드:** CartInfo 중첩 결제 상세 6객체의 String 59개는 응답 `raw`로만 보존합니다.
보호된 enum·리터럴 평문과 실서버에서 관측하지 않은 필드 형식은 검증 못 함입니다.
2.x 공개 메서드 85개 행의 7.0.10 정적 검토는 전체 wire 계약·모든 분기·실서버 호환의 증명이 아닙니다.
DynaPath 조건부 문자열·nullable code, 통합결제의 일반 회원 분기, 서비스 상태 기본값 전송·N카드는 미확정입니다.

[실행 방법](README.md)의 두 검사가 모두 종료 코드 0이어야 합니다. 통과는 실서버 수용의 증거가 아닙니다.

파싱·요청의 공통 규칙과 18개 필드 목록은 [동작 계약](BEHAVIOR.md)에 있습니다.
