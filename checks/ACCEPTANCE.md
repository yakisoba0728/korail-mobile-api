# 합격 기준

판정은 이 문서를 기준으로 합니다.

번호가 G9 부터 시작하는 것은 G1~G8 을 폐기했기 때문입니다(§5). 코드와 커밋이 G9~G11 을
그 번호로 부르고 있어 번호는 그대로 둡니다.

## 1. 보장 (위반하면 결함, 반드시 수정)

| ID | 보장 |
|---|---|
| G9 | 변경(mutation) 요청의 응답을 받은 뒤 typed 파싱이 실패하면, 예외의 `.raw` 는 **받은 응답 전체**다(예외가 이미 부분 raw 를 갖고 있어도). 재전송하지 않는다. |
| G10 | `from korail_mobile_api import *` 와 모든 하위 모듈 import 가 성공하고, `__all__` 의 모든 이름이 정의돼 있다. |
| G11 | `logout()` 은 서버 호출이 어떻게 실패하든 로컬 세션·쿠키를 비운다. |

## 2. 파서 동작

- **선택 필드는 관대하게 읽습니다.** 타입이 이상한 스칼라는 `None`, 목록·객체 자리에 목록·객체가
  아닌 값이 오면 빈 값, 목록 안의 깨진 원소는 건너뜁니다. 선택 필드 하나 때문에 응답 전체를
  거절하지 않습니다. 원문은 언제나 `raw` 에 있습니다.
- **필수 필드는 엄격합니다.** 응답 봉투, 그리고 정확성에 필요한 값(예: 예약 응답의 PNR, 코드가
  일부러 검증하는 금액 필드)은 없거나 모양이 틀리면 `KorailProtocolError` 입니다.

이 패키지는 로그·예외·`raw` 의 내용을 **가리지 않습니다.** 무엇을 어디에 기록할지는 호출자가
정합니다.
