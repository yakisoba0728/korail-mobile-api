# 오프라인 검사 기준

## 검사하는 계약

**G9 — 변경 응답 파싱 실패:** `.raw`에 전체 응답을 남기고 자동 재전송하지 않습니다.
`KorailApiError`는 유형을 유지하며 부분 원문은 `.parser_raw`에 옮깁니다. 다른 예외는 `KorailProtocolError`로 감쌉니다.

**G10 — 공개 표면:** 전체 하위 모듈과 star import가 성공하고 `__all__`의 이름이 모두 정의돼 있어야 합니다.
이 검사는 각 공개 API의 정상 동작이나 모든 모델의 필드 의미를 검증하지 않습니다.

**G11 — 로그아웃 정리:** 서버 로그아웃 중 예외가 발생해도 로컬 세션·쿠키를 비우고 예외를 전파합니다.
서버 세션 무효화 성공은 보장하지 않습니다.

## 파서·원문과 한계

선택값은 대체로 관대하게 읽되 파서별 조건을 따릅니다. 리무진 `trainList`·`seatList`는 생략·null이면 빈 목록이며,
비목록이나 비객체 행은 거절합니다. 좌석 재고·호차·역 목록에서 필수로 잘못 읽던 선택 필드 18개는 빠지면 앱 기본값(""·`None`)이고,
예약 신원·금액 등 필수값은 검증합니다. 개별 파서를 직접 호출하면 성공 여부·봉투 타입을 다시 검사하지 않을 수 있으며 모든 하위 객체가 `raw`를 갖지는
않습니다. 파싱 실패 때의 전체 `.raw`·`.parser_raw` 는 직접 호출해도 같습니다.
로그·예외·`raw`는 **마스킹하지 않으므로** 기록·노출은 호출자 책임입니다.

**L7 — 미모델링 필드:** CartInfo 중첩 결제 상세 6객체의 String 59개는 응답 `raw`로만 보존합니다.
보호된 enum·리터럴 평문과 실서버에서 관측하지 않은 필드 형식은 검증 못 함입니다.

[실행 방법](README.md)의 두 검사가 모두 종료 코드 0이어야 합니다. 통과는 실서버 수용의 증거가 아닙니다.
