# 합격 기준

번호가 G9 부터인 것은 G1~G8 을 폐기했기 때문입니다. 코드와 커밋이 그 번호로 부르고 있어 그대로 둡니다.

## 1. 보장

| ID | 보장 |
|---|---|
| G9 | 변경 응답의 타입 파싱 실패 시 예외 `.raw`에 받은 응답 전체를 보존한다. 기존 부분 원문은 `.parser_raw`에 보존하며 자동 재전송하지 않는다. |
| G10 | star import와 모든 하위 모듈 import가 성공하고 `__all__`의 모든 이름이 정의돼 있다. |
| G11 | `logout()`의 서버 호출이 실패해도 로컬 세션·쿠키를 비운다(실패 예외는 그대로 올라온다). 서버 무효화 성공을 보장하지는 않는다. |

## 2. 파서와 원문

선택 필드는 대체로 관대하게 읽지만 모든 목록·행에 같은 규칙이 적용되지는 않습니다.
리무진 `trainList`·`seatList` 는 없거나 `null` 이면 빈 목록이고, 목록이 아닌 값이나 비객체 행은
오류입니다. 일반 좌석 재고도 필수 구조·필드를 검사합니다. 정확한 조건은 각 파서와 입력 모델을 따릅니다.

전송 봉투와 예약 신원·금액 등 필수 값은 검증합니다. 직접 호출하는 개별 파서 모두가 봉투·성공 여부를
재검사하는 것은 아닙니다. 원문은 응답 또는 예외에 보존되지만 모든 하위 값 객체에 `raw`가 있는 것은 아닙니다.
로그·예외·`raw`는 **마스킹하지 않으므로** 호출자가 저장·노출 범위를 정해야 합니다.

## 3. 알려진 한계

| ID | 한계 |
|---|---|
| L7 | CartInfo 중첩 결제 상세 6객체의 String 59개는 타입화하지 않고 응답 `raw`에 보존한다. 보호된 enum·리터럴의 평문과 캡처 없는 필드의 실제 서버 형식은 미확인이다. |

## 4. 실행

```sh
python3 checks/contract_api.py      # G9·G10·G11
python3 checks/netfunnel_offline.py # MockTransport 9건
```

종료 코드: **0 통과 / 1 실패 / 2 검사 불완전**. 의존성은 `httpx`, `cryptography`입니다.
검사 범위 밖의 API나 실서버 수용 여부는 이 결과로 판정하지 않습니다.
