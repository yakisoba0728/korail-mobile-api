# 합격 기준

판정은 이 문서를 기준으로 합니다.

번호가 G8 부터 시작하는 것은 G1~G7(마스킹)을 2026-09-23 에 **폐기**했기 때문입니다.
코드와 커밋이 G8~G11 을 그 번호로 부르고 있어 번호는 그대로 둡니다. 폐기 이유는 §7 에 있습니다.

## 1. 보장 (위반하면 결함, 반드시 수정)

파서·클라이언트

| ID | 보장 |
|---|---|
| G8 | 기준 wheel `korail_mobile_api-1.1.1`(로컬 `analysis/reports/7.0.6-additions/dist/`, 감사 묶음에서는 따로 둔 `korail-g8-baseline-1.1.1.whl` 을 `--wheel` 로)이 받아들이던 응답을, 1.1.1 이후 모델링한 필드·중첩 객체 때문에 거절하지 않는다. 비교 대상은 1.1.1 이 `parse_*` 를 정의한 모듈 전부이고, `checks/g8_differential.py` 가 두 버전에 **유한한 생성 입력 행렬**을 넣어 비교한다 — 전칭 증명이 아니라 그 행렬 안에서의 확인이다. 1.1.1 파서가 사라지면 허용 목록(커밋 근거)에 있어야 한다. 1.1.1 에 이미 있던 필드의 입력·반환 정책 변경은 G8 이 아니라 문서(D)로 다룬다. |
| G9 | 변경(mutation) 요청의 응답을 받은 뒤 typed 파싱이 실패하면, 예외의 `.raw` 는 **받은 응답 전체**다(예외가 이미 부분 raw 를 갖고 있어도). 재전송하지 않는다. |
| G10 | `from korail_mobile_api import *` 와 모든 하위 모듈 import 가 성공하고, `__all__` 의 모든 이름이 정의돼 있다. |
| G11 | `logout()` 은 서버 호출이 어떻게 실패하든 로컬 세션·쿠키를 비운다. |

## 2. 알려진 한계 (결함 아님, 수정하지 않음)

L 은 G 가 **명시적으로 다루지 않는 입력**에만 적용됩니다. G 에 해당하는 입력을 L 로 면제할 수 없습니다.

| ID | 한계 |
|---|---|
| L7 | CartInfo 중첩 결제 상세 6객체(String 59개), 보호된 enum·리터럴의 평문, 라이브 캡처 없는 필드의 실제 서버 형식. **G8 의 관대성은 L7 로 면제되지 않는다.** |

이 패키지는 로그·예외·`raw` 의 내용을 **가리지 않습니다.** 이 패키지가 만드는 예외
메시지에는 자격증명·세션 값을 넣지 않고, 서버가 준 문구와 원문은 그대로 둡니다. 무엇을
어디에 기록할지는 호출자가 정합니다. 이것은 설계이지 결함이 아닙니다.

## 3. 문서

주석·독스트링의 7.0.6 관련 사실 주장은 **검증됐거나, 미출처·추정이라고 표기돼 있어야** 한다.
선언 위치(`@SerialName`, 필드 선언)는 이름·선언 타입의 근거일 뿐, 실제 서버 응답이나
"항상·유일·전혀" 같은 전칭 주장의 근거가 아니다. 어긋나면 D 이다.

## 4. 판정 분류

| 분류 | 뜻 | 처리 |
|---|---|---|
| **C** | 보장(G8~G11) 위반, **또는** G 에 적히지 않았더라도 실제 동작 버그(크래시, 데이터 손실, 상태 누수), 검사기의 거짓 통과·거짓 실패·비정상 종료 | 수정. 수정마다 `checks/` 에 회귀 사례 |
| **D** | 문서·주석·배포물 결함 | 일괄 수정 |
| **L** | §2 한계에 해당(G 와 겹치지 않을 때만) | 수정하지 않음 |
| **N** | 기준에 없는 새 기대·정책 제안 | 기록만 |

## 5. 종료 규칙

1. C 와 D 만 고친다. L·N 은 고치지 않는다.
2. 고친 뒤에는 감사가 준 **재현 입력을 다시 돌려** 항목별 결과를 낸다.
3. 그 결과에 대한 확인에서 **새 C 가 나오지 않으면 종료**다.

## 6. 실행 가능한 기준

종료코드: 0 통과, 1 실패, 2 검사 불완전(입력을 못 읽음, 검사기 자체 예외 등).

```sh
python3 checks/contract_api.py         # G8(표본)·G9·G10·G11
python3 checks/g8_differential.py      # G8 (기준 wheel 없으면 2; --wheel PATH)
python3 checks/sphinx_symbols.py       # 문서의 파이썬 심볼 참조
python3 checks/decompile_citations.py  # 문서의 디컴파일 인용 (analysis/ 없으면 2)
python3 checks/selftest/run.py         # 검사기 자체의 거짓 통과·실패
```

  모듈에서 G8 회귀 7군이 드러나 고쳤습니다.
- 2026-09-23: **마스킹 G1~G7 과 한계 L1~L6·L8 을 폐기**하고 `redaction.py`·`redact_*` 공개
  함수·예외 메시지 마스킹·마스킹 검사 두 개를 지웠습니다. 개인이 자기 계정으로 쓰는
  라이브러리가 로그 마스킹까지 보장할 이유가 없었습니다. 게다가 자유 텍스트 마스킹은 닫히지
  않는 문제라, 감사마다 새 입력 모양(set·float·튜플 키·URL 폴백 …)이 나와 끝나지 않았습니다.
  같은 날 `live.live_enabled`·`live.read_credentials_from_env` 도 지웠습니다(패키지 안에서
  쓰는 곳이 없던 스모크 도우미).
